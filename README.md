# Tempo website

Privacy policy and support pages for the Tempo iPhone app in Turkish, English and German, published with GitHub Pages at https://ada88.github.io/tempo-app/.

- `tr/`, `en/`, `de/`: `privacy.html` and `support.html` for each language. The app links to these exact paths, so do not rename them.
- Plain HTML and CSS: no JavaScript, cookies, analytics or web fonts.
- The pages describe what the app really does. When the app's handling of data changes, update them before the new version is released and change the date at the top.
- iOS menu names (for example "Tam Konum", "Geliştiricilerle Paylaş") are quoted exactly as iOS shows them; check them against the current iOS when editing.
- The contact email `adatech.tr@gmail.com` is on all six pages. The privacy policy's email section names Gmail as its provider: update that section if the address moves.

The app's source code is not in this repository.
